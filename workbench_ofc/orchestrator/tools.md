# Orchestrator tools

| Tool | Description | Technical | Use when | Do not use when | Error feedback |
|------|-------------|-----------|----------|-----------------|----------------|
| `invoke_agent` | Starts one agent with a scoped brief and incident id | **In:** `agent_id`, `incident_id`, `brief{}`. **Out:** `run_id`, `status`. **Connector:** internal runtime. **Side effect:** starts agent run (no vendor write). | A stage needs specialist work | You already have the answer in the evidence pack | `Unknown agent` / `Agent busy` |
| `collect_evidence` | Merges agent JSON into the shared evidence pack | **In:** `incident_id`, `agent_id`, `payload{}`. **Out:** `evidence_version`. **Connector:** Cognitive Bridge (index). **Side effect:** append-only merge. | After every successful agent return | Before the agent finished | `Empty payload` |
| `open_investigation_loop` | Re-invokes Diagnostic for more evidence | **In:** `incident_id`, `reason`, `focus[]`. **Out:** `loop_id`, `budget_left`. **Connector:** internal. **Side effect:** increments loop counter. | Diagnose confidence below threshold | Resolve started without HITL reset | `Loop budget exceeded` |
| `open_recovery_failure_loop` | Stops automation path and escalates | **In:** `incident_id`, `failed_job_id?`, `reason`. **Out:** `loop_id`. **Connector:** PagerDuty (escalate) + internal. **Side effect:** pauses automation lane. | Verification unstable or job failed | Soft retry still within policy | `Already in recovery-failure loop` |
| `request_hitl_approval` | Sends a gate packet to the human channel | **In:** `gate`, `packet{}`, `channel`. **Out:** `approval_request_id`. **Connector:** Teams / email. **Side effect:** notify human; blocks gated action. | Any configured HITL gate | Informational status only | `Gate not configured` |
| `manual_takeover` | Pauses agents; marks human owner | **In:** `incident_id`, `user_id`. **Out:** `mode=manual`. **Connector:** ServiceNow (owner field) + internal. **Side effect:** pause agents. | Engineer requests control or extreme risk | Soft advisory notes | `Already in manual mode` |
| `update_progress` | Writes stage + summary to ServiceNow and Bridge | **In:** `incident_id`, `stage`, `summary`. **Out:** `ok`. **Connector:** ServiceNow REST+MCP, Cognitive Bridge. **Side effect:** write work notes / stage. | Stage transitions | No material change | `Write denied by ACL` |
| `emergency_kill_switch` | Halts all agent and automation for this incident | **In:** `incident_id`, `reason`. **Out:** `halted=true`. **Connector:** internal + automation APIs (cancel). **Side effect:** hard stop. | Runaway automation / safety event | Ordinary pause | `Kill-switch already active` |
